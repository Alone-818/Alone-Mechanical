# Alone Mechanical 科技线审计与整理

> 审计日期：2026-10-21  
> 范围：当前正式配方、机器代码、资源生成脚本，以及当前科技树、机器制造、核安全和维度转换文档。  
> 本文只记录审计与建议，不直接修改玩法参数。

## 1. 总结

当前模组已形成五阶段路线：

手工起步 → 钢与机械 → 电解液工业 → 高级能源 → 末地工业

资源目录约有 258 条正式 JSON 配方，机器配方覆盖粉碎、合金、锻压、塑形、灌注、反应、分离、蒸馏、冷凝、换热、核燃料、农业、维度转换和虚空再造。发电、抽液、范围机器、涡轮和部分反应堆行为由代码驱动，不能只按 JSON 数量判断功能是否存在。

当前主要问题不是内容不足，而是：

- 入口和下一步目标不够显式。
- 氯气、封装核废物等副产物没有下游。
- 高级能源阶段跨度过大。
- 历史路线图与当前实现混在一起。
- 部分后期系统的经济性可能压过前期产线。

## 2. 推荐游玩流程

1. 原版采集铁、铜、红石、煤/木炭。
2. 制作基础电路、工业核心、控制器、能量矩阵、机壳、仓储和端口。
3. 建立燃料或太阳能发电、电网、电动泵和一级管道。
4. 粉碎粗铁/铜/金，制作碳粉，并用合金机炼钢。
5. 用钢制作锻压、塑形、反应、分离、蒸馏和冷凝组件。
6. 制作板材、铜线、钢齿轮，进入空气分离和水电解。
7. 建立硫酸线：硫 → 二氧化硫 → 三氧化硫 → 硫酸气体 → 液态硫酸。
8. 用氧气和硫酸分别开启 3 倍、5 倍矿物加工。
9. 由氢气分离或水富集生产重水，准备钍燃料和末地转换液。
10. 由铀矿 → 铀粉 → 浓缩铀；再选择水冷或钠冷核反应堆。
11. 用蒸汽、锅炉、交换塔和涡轮建立高功率电网。
12. 制作高级电池、处理矩阵、四级管道和高级电池变体。
13. 用重水和爆裂紫颂果生产末地转换液，启动并扩增虚空液。
14. 用种子锭和虚空液再造铁、铜、金、铀矿石，制作末地电路和五级管道。

## 3. 分阶段审计

### 阶段 0：手工起步

已实现：基础电路、工业核心、发电、电网、储能、泵、粉碎机、合金机和一级物流。

风险：首台能量矩阵、首台机器和首个供电来源必须互相不循环。建议持续验证“只靠原版资源即可完成第一套电网”。

### 阶段 1：钢与机械

核心链：

粗矿 → 粉碎 → 粉末  
煤/木炭 → 碳粉  
铁粉 + 碳粉 → 钢锭  
钢锭 → 板材、线材、齿轮和机器组件

现状基本连通。问题是材料加工与机器结构分散在不同文档，玩家不容易知道下一台机器的具体材料。建议在阶段进度中增加“推荐下一台机器”和“解锁理由”。

### 阶段 2：电解液工业

核心链：

空气分离 → 氮气、氧气  
水电解 → 氢气、氧气  
水蒸馏/冷凝 → 蒸汽、富集水  
硫酸 → 高级矿物加工  
氮气 + 氢气 → 氨气 → 肥料  
初级/中级/高级电解液 → 对应电池

这条线完整，但硫酸依赖蒸汽，重水依赖多台处理设备。建议在教程和进度页显示介质来源及回收去向，减少“有配方但不知道前置”的问题。

### 阶段 3：高级能源

核心链：

铀矿 → 铀粉 → 铀矿浆 → 浓缩铀燃料  
贫化铀粉 + 重水 → 钍燃料  
核废液 → 回收燃料颗粒 + 封装核废物  
燃料 + 水 → 蒸汽  
燃料 + 液态钠 → 高温液态钠 → 锅炉/交换塔 → 蒸汽  
蒸汽 → 涡轮 → FE

当前核反应堆已经有余热、停堆、爆炸和辐射逻辑。需要在所有文档中统一说明：缺燃料只会停止继续燃烧，余热仍需处理；涡轮目前消耗蒸汽但不产乏汽，因此水冷路线是开放系统。

### 阶段 4：末地工业

核心链：

重水 + 爆裂紫颂果 → 末地转换液  
末地转换液 + 水 → 虚空液  
虚空液 + 水 → 虚空扩增  
种子锭 + 虚空液 → 矿石再造  
高级电路 + 末地转换液 → 末地电路  
量子芯片 → 五级管道

虚空再造已经有实际消耗端。需要明确说明它不能首次提供铀：铀再造仍要求先拥有铀锭；输出为矿石方块，必须重新采掘后才能进入粗矿加工。

## 4. 发现的问题和建议

### P0：发布前必须统一

| 问题 | 影响 | 建议 |
| --- | --- | --- |
| 历史路线图仍描述旧缺口 | 开发者会误判功能状态 | 在旧文档顶部标注“历史盘点”，统一链接当前科技树和本文 |
| 核反应堆旧说明与当前安全机制相反 | 教程和实现不一致 | 统一引用核安全文档 |
| 配方数量手工写入多个文档 | 容易过期 | 以资源生成脚本为单一来源，文档只保留摘要 |
| 阶段名称在教程、进度、语言文件中可能漂移 | 玩家认知不一致 | 维护一份阶段名称表并由生成脚本复用 |

### P1：建议优先实现或定案

| 断点 | 当前表现 | 建议 |
| --- | --- | --- |
| 氯气无下游 | 只能保存或排放 | 增加盐酸、漂白剂、氯化物或树脂支线 |
| 封装核废物无下游 | 只能长期堆存 | 增加玻璃化、深埋或长期封存块，保留储存成本 |
| 蒸汽无回收 | 水冷核电需持续补水 | 增加涡轮冷凝器，设置少量热损耗 |
| 高级能源阶段过宽 | 核能、钠冷、涡轮、处理矩阵同时出现 | 拆成“核燃料”“热工发电”“高阶电网”三个子阶段 |
| 钠冷收益可能过高 | 可能完全替代水冷 | 调整换热倍率，或增加钠损耗和维护成本 |
| 虚空再造可能替代采矿 | 后期资源获取过于稳定 | 增加时间、电力、种子锭或副产物成本，保留高级倍产的速度优势 |

### P2：体验优化

- 在 JEI 和机器 GUI 显示原料来源、下游用途、是否可回收。
- 在教程中显示单位矿石的总 FE、酸耗、氧耗和最终产量。
- 为量子阶段增加终局目标，例如量子处理矩阵、远程端口或跨区块物流。
- 为高级电池变体增加维护或材料代价，避免只看面板倍率。
- 让农业、氯化学和树脂/塑料形成互相支撑的副线。

## 5. 推荐新增支线

### 化工闭环

氯气 + 氢气 → 盐酸  
盐酸 + 玻璃/矿物 → 氯化物或清洗液  
氯气 + 水 → 漂白剂  
氨气 + 硫酸 → 硫酸铵肥料

### 核废物闭环

核废液 → 回收燃料颗粒 + 封装核废物  
封装核废物 + 玻璃/铅 → 长期封存块  
长期封存块 → 终端储存或低速衰变

### 蒸汽回收

蒸汽 → 涡轮 → 乏汽 → 冷凝器 → 水

建议冷凝器消耗少量电力或冷却液，并保留小比例水损耗，避免无限免费循环。

## 8. 总体改造原则

目标不是单纯增加配方数量，而是让每个阶段都有输入资源、产出目标、下一步机器和回收/替代路线。

建议把科技门槛分成三层：

- 材料门槛：矿物、维度材料或副产物。
- 设备门槛：组件、仓储、端口和机器。
- 运行门槛：FE、冷却介质、废料空间和物流吞吐。

建议将五阶段细分为八个节点：

| 节点 | 名称 | 解锁重点 |
| --- | --- | --- |
| T0 | 工业起步 | 电网、粉碎、基础仓储 |
| T1 | 钢与机械 | 合金、锻压、塑形、二级物流 |
| T2 | 基础化工 | 空气分离、水电解、蒸馏 |
| T3 | 矿物强化 | 氧气净化、硫酸、3/5 倍加工 |
| T4 | 电池与农业 | 电解液、电池、氨和肥料 |
| T5 | 核燃料 | 铀、重水、钍、MOX |
| T6 | 热工能源 | 反应堆、锅炉、交换塔、涡轮 |
| T7 | 末地量子 | 虚空再造、量子材料、五级物流 |

每个节点应有 1 个核心目标、2～4 个必须机器、1 个阶段芯片、1 个里程碑产物和 1 个不阻塞主线的可选支线。

## 9. 现有系统改造方案

### 9.1 文档和数据源

1. 将当前科技树、机器制造、电池、核安全、维度转换和配方清单标记为当前版本。
2. 将旧路线图标记为历史记录，并在顶部链接当前文档。
3. 由资源生成脚本输出配方数量、机器数量、未被引用的物品、没有下游用途的副产物。
4. 在构建检查中加入文档快照检查，数量变化时提示更新。
5. 为每条主线设置唯一入口文档，其他文档只保留细节和链接。

验收：每条正式配方都能追溯到阶段、机器和至少一个下游用途；新终端副产物能被自动列出。

### 9.2 机器蓝图

增加“机器蓝图”教程/进度物品，不参与实际消耗。获得蓝图后显示核心、组件、仓储列、端口、前置材料；工程锤检测失败时显示缺失部件。

蓝图分为基础加工、化工、热工和终局四组。JEI 将机器结构、制造配方和加工配方放在同一入口。

### 9.3 能源分层

| 电源 | 定位 | 建议限制 |
| --- | --- | --- |
| 燃料发电 | 启动电源 | 低效率，适合短期运行 |
| 太阳/月光 | 被动补充 | 不能单独支撑重工业 |
| 水冷核电 | 第一种高功率 | 持续耗水并产生废料 |
| 钠冷核电 | 高级热工路线 | 需要钠库存和换热设备 |
| 量子能源 | 终局电源 | 需要虚空材料和稳定器 |

统一显示每种电源的单位燃料 FE、冷却消耗、废料产生量和物流吞吐，方便平衡。

### 9.4 蒸汽回收

增加涡轮冷凝器：

蒸汽 → 涡轮 → 乏汽 → 冷凝器 → 水

建议每 1000 mB 蒸汽产生 900～950 mB 乏汽，冷凝回收 850～900 mB 水；冷凝器消耗少量 FE 或冷却时间，水冷总损耗保持 5%～15%。钠冷的高温钠应回流，但允许极低比例损失。

## 10. 扩展化工科技线

### 10.1 氯化学

基础层：氯气 1000 mB + 氢气 1000 mB → 盐酸 1000 mB。用于清洗矿物、氯化铁和氯化铜。

中级层：氯气 500 mB + 水 1000 mB → 漂白剂 1000 mB。用于玻璃、纸张、纤维和农业消毒。

高级层：氯气 + 碳粉 + 氢气 → 氯化树脂。用于高级电缆外皮、四级/五级管道和量子设备绝缘层。

### 10.2 氨与肥料

增加：

- 氨气 + 硫酸 → 硫酸铵肥料。
- 氨气 + 二氧化碳 → 尿素。
- 尿素 + 水 → 高效肥料。

高效肥料只提高收割塔效率，不直接增加矿物产量，让氮气、氢气、硫酸和农业形成支线。

## 11. 扩展核能和废料科技线

三种燃料应有不同定位：

| 燃料 | 优点 | 缺点 |
| --- | --- | --- |
| 浓缩铀 | 制作简单，输出稳定 | 废料和事故等级中等 |
| 钍 | 需要重水，废料较少 | 产线复杂，功率较低 |
| MOX | 减少天然铀消耗 | 依赖回收颗粒和贫化铀 |

新增核废物处理：

1. 核废液 → 回收燃料颗粒 + 封装核废物。
2. 封装核废物 + 玻璃 + 铅 → 长期封存块。
3. 长期封存块 → 核废料库或深埋结构。

长期封存块不应再次变回燃料，避免免费循环。新增辐射探测器、屏蔽门、冷却控制器、废料阀和应急冷却液，形成核安全支线。

## 12. 扩展材料和制造科技线

下界合金粉建议独立定位：

下界合金锭 → 粉碎 → 下界合金粉

用途：高温密封件、核堆强化外壳、涡轮耐热轴承和量子设备耐热接口。

增加高级导线：

- 铜线 + 氯化树脂 → 绝缘铜线。
- 绝缘铜线 + 共振锭 → 超导线。
- 超导线 + 超导锭 + 重水 → 低损耗线圈。
- 低损耗线圈 → 量子处理矩阵组件。

## 13. 扩展物流和自动化科技线

五级管道之后增加功能，而不是只增加速率：

- 过滤管：按物品、流体或气体 ID 分流。
- 优先级管：在多个目标之间分配资源。
- 缓冲阀：减少机器输出堵塞。
- 远程端口：跨区块传输但持续耗 FE。
- 物流监控器：显示吞吐、缓存和阻塞端点。

配套增加过滤芯片、优先级芯片和远程芯片。芯片只提升自动化稳定性，不直接增加产量。

## 14. 量子终局科技线

建议路线：

1. 末地电路 + 超导线 → 量子控制器。
2. 量子控制器 + 虚空液 → 虚空稳定器。
3. 虚空稳定器 + 低损耗线圈 → 量子处理矩阵。
4. 量子处理矩阵 + 五级管道 → 远程物流端口。
5. 远程物流端口 + 核废料库 → 终端自动化工厂。

量子设备需要虚空液维护和五级物流；结构损坏时清空部分缓存，奖励自动化、稳定性和空间压缩，不直接提供无限矿物或无限 FE。

## 15. 分批实施计划

### 批次 A：文档和验证

统一阶段名称；生成配方、材料和副产物审计报告；修正文档链接；增加首台机器、首个核燃料和首个虚空液的完整 GameTest。

### 批次 B：热工和核废物

增加乏汽、冷凝器、长期封存块、废料库、辐射探测和应急冷却；为水冷、钠冷和 MOX 增加统一收支测试。

### 批次 C：化工扩展

增加盐酸、漂白剂、氯化物/树脂、尿素/硫酸铵肥料；将树脂接入高级导线和管道；补充 JEI、教程和语言键。

### 批次 D：材料和物流

增加下界合金粉用途、绝缘铜线、超导线、低损耗线圈、过滤管、优先级管、缓冲阀和远程物流。

### 批次 E：量子终局

增加量子控制器、虚空稳定器、量子矩阵、远程端口和终端自动化；补充结构、缓存恢复、客户端 GUI 和崩溃恢复测试。

## 16. 通用验收标准

每个新增机器或配方必须同时完成正式 JSON、中英文语言键、JEI 分类、教程/进度入口、缺料/堵塞/缺电/读档测试、机器解体和端口方向测试、资源生成脚本更新，以及至少一条完整生存路径测试。
