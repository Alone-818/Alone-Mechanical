# 机器设置更新

## 养殖与屠宰

主界面的“按种类配置数量”打开独立列表，默认只列出工作范围内或已经配置的生物。可切换全部生物，或直接按本地化名称、注册 ID 搜索。养殖列表只显示动物。

每种生物单独显示范围内数量、启停状态和数量设置。屠宰数量表示至少保留多少只；养殖数量表示总数量上限，幼崽计入。加减按钮每次变化 1，Shift 点击变化 10；输入数字后回车、离开输入框、翻页、返回均会保存，也可点“保存修改”。服务端回传配置后显示“已与服务端同步”。关闭种类不会清除它的数量设置。返回主界面可以继续操作食物仓。

## 通用气体输出策略

所有产生气体的机器均在主界面提供“气体排出”入口，输出1、输出2分别设置：

| 模式 | 行为 |
|---|---|
| 内部保存 | 默认值；所有气体必须存下，输出空间不足则整批暂停 |
| 仅排出多余 | 存入可用空间，其余产气丢弃，其他产物继续生产 |
| 全部排出 | 立即清空本输出通道现有气体，并丢弃以后的产气 |

输入、液体和物品不受排气设置影响。其他产物仍需有空间；缺少原料或电力仍会暂停。策略随控制器存档保存，旧存档默认全部保存。适用于内部缓存和连接实际储罐的配方机器，包括分离塔、其他塔、分离器、反应釜、气液转换器和锅炉等。

## 塔的处理强度

滑块继续控制批次容积。每份配方的 FE/t 在实际批量和线圈之外，还乘以 `1 + 强度 / 100`；10% 为1.1倍，100%为2倍，向上取整。

空气分离默认配方改为每份 400 mB 氮气 + 100 mB 氧气、100 tick、基础20 FE/t。最大批次预算改为每立方米100 mB，缓存仍是每立方米1000 mB。小塔低档保证至少一份批次。最小45 m³塔：10%档每100 tick一份，耗22 FE/t；100%档每100 tick九份，耗360 FE/t。最大产气速率为旧默认值的1/50。配置项 `airSeparationBatchMbPerCubicMeter` 可调整最大批量。

## 教程和组件

教程左侧为固定行高的可滚动目录，支持滚轮和拖动滚动条；右侧为独立正文，支持翻页按钮、页码、方向键、PageUp/PageDown及滚轮。滚动目录不改变正文，翻正文页也不移动目录。缩小窗口时减少目录可见行数、重新分页，Esc关闭教程。

分解组件统一使用 `alone_mechanical:decomposition_component` 物品。旧 `separation_core` 方块仍可运行、拆除或选取时得到统一组件；旧物品通过缺失映射迁移。JEI与创造物品栏不再出现重复物品。

机器方块暂时没有工作台配方，包括核心、组件、结构、仓储、端口、管道和发电机；材料、工具、电池及机器内部加工配方保留。资源生成脚本最后会移除这些方块合成配方，避免重新生成。
