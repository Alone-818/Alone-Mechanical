# 配方依赖审计

运行 `pwsh -File docs/recipe-dependency-audit.ps1` 会扫描正式 `machine` 配方和它们的物品、流体、气体输入输出，列出没有下游消费者的产物。工作台配方的输入输出也应在后续版本加入同一份审计。

当前重点支线已接入：

- 液态虚空输出进入矿石再造和下一批循环启动储备。
- 红石、青金石、钻石和绿宝石都有直接粉碎、净化/破晶和虚空矿石再造入口。
- 核废液分离为回收燃料颗粒与封装核废物；封装核废物没有还原燃料配方。
- 滑索挂钩、电网分析仪和合成组件都有正式工作台配方和 JEI/教程入口。
- 过滤芯、优先级芯片和维护电池包都有正式工作台配方；过滤规则与优先级保存于管道方块实体 NBT，并由服务端转移逻辑执行。
