# 核燃料与农业化工

本次新增11个机器配方、4个铀熔炼/高炉配方，使用既有机器与升级系统。全部数量为游戏配方参数。

初始粗铀来自主世界自然生成的铀矿和深层铀矿，需铁镐及以上采掘。生成高度Y=-64～64，Y=0附近最集中，每区块尝试8个矿脉、矿脉尺寸8；丰度定位比铁少、比普通群系金矿多，保留恶地额外金矿。旧存档需探索新生成区块。详见[铀矿自然生成](uranium-worldgen.md)。

反应釜使用工业核心＋化合组件，仓储介质决定模式；分离器使用分解组件。核废液回收和铀矿浆分离均为一个液体输入、两个独立物品输出。输出堵塞时不消耗原料或FE。

浓缩铀、MOX、钍液态成品使用现有核反应堆配方，冷却介质及核废液产生比例保持原规则。MOX每轮都需要补充贫化铀粉；封装核废物为最终产物，不提供重新制燃料配方。钍的游戏化来源依赖重水，普通水、富集水不能代替实际消耗的100 mB重水。

粗铀和铀粉均有熔炉200 tick、高炉100 tick的1:1铀锭配方。电弧炉沿用既有原版熔炼配方读取逻辑。

氮气可来自空气分离塔，氢气来自水电解。一次合成氨产生2000 mB，可配合4骨粉制造16肥料。

## 肥料使用

手持肥料右键未成熟的CropBlock作物，每份增加2级生长，最高到成熟；成熟作物及非作物不消耗。支持小麦、胡萝卜、马铃薯、甜菜根和兼容CropBlock的模组作物，不额外影响动物或地狱疣。

收割塔可增加输入1物品仓，通用端口紧贴仓列顶部/底部。GUI左侧为可选肥料输入，右侧为收获输出；物品管可自动供应。没有输入仓或肥料时继续普通收割，不要求重建旧塔。新增仓储后用工程锤重检即可。

一次施肥使用一份肥料，占用一个工作动作；每周期动作数依照现有并行量。施肥推进到成熟后，由后续动作收割，保留原有种植物并重置生长。输出所有格子均已满时暂停施肥。自动操作仍由机器成型、供电、效率线圈及处理矩阵控制。

快速搭建收割塔现在自带肥料输入仓。Shift快速移动仅将肥料放入该输入区；其他物品不误入。

## 资源与验证

新增7种物品均有原生16×16材质；铀矿浆与氨使用现有动态介质渲染，创造储罐自动覆盖。新增教程章节“核燃料制备与回收”“合成氨与农业化工”；各配方自动进入JEI对应分类。

资源生成：`tools/generate_fuel_agriculture_resources.ps1`，接入完整资源生成和帮助更新。无界面回归入口：`tools/fuel-agriculture-tests.gradle`。测试覆盖实际机器加工、输出堵塞、存档恢复、重水不可替代、手动及自动施肥、GUI槽位和配方网络同步，并运行相关既有核反应堆、重水、农业及创造储罐测试。

铀锭入口已补齐：1铀锭经粉碎机得1铀粉；或4铀锭＋1000 mB硫酸经固液溶解得1000 mB铀矿浆。详见 [蒸馏路线与核燃料](distillation-and-reactor-fuel.md)。
