# 维度转换液与灌注

两种流体分别为 `alone_mechanical:nether_dimension_conversion`（深红色）和
`alone_mechanical:end_dimension_conversion`（末地石色乳白色）。使用现有流体储罐、
流体管道与灌注机接口；专用桶已移除，创造栏提供对应无限供给储罐。
高效地狱转换液由烈焰粉＋岩浆制备；未去地狱时可用黑曜石＋岩浆走高成本替代路线。高效末地转换液由爆裂紫颂果＋重水制备；未去末地时可用末影珍珠＋重水走高成本替代路线。
水与地狱转换液可制岩浆，水与末地转换液可启动液态虚空生产。
液态虚空取得启动量后可持续供水、供电扩增，详见同目录的 `dimension-fluid-production.md`。

每份配方：输入1放1个物品，输入2提供250 mB对应流体，输出1得到1个产物；
基础100 tick、40 FE/t。支持通用线圈和处理矩阵。

| --- | --- | --- |
| 种子 | 地狱疣 | 紫颂果 |
| 青金石 | 石英 | — |
| 红石 | 萤石粉 | — |
| 粘土块 | 地狱岩 | — |
| 圆石 | 黑石 | 末地石 |
| 沙子 | 灵魂沙 | — |
| 石头 | 玄武岩 | 末地石 |
| 花朵 | 绯红菌 / 诡异菌，各50% | 紫颂花 |
| 藤蔓 | 垂泪藤 / 缠怨藤，各50% | — |
| 水瓶 | — | 龙息瓶 |

种子标签为 `alone_mechanical:dimension_conversion_seeds`，包括原版6种种子和可选的
`forge:seeds`。花朵使用 `minecraft:flowers`。水瓶使用 `forge:partial_nbt` 校验
`Potion: minecraft:water`，其他药水和空瓶不参与。

配方字段 `alternate_output` 为灌注机输出1的互斥备选产物，各50%。主产物与备选
数量必须相同且物品不同，不能将它用于其他机器。每份并行配方独立随机；检查匹配
和输出空间时不抽取随机数，完成且复核成功后才抽取。单份只需一个空槽；并行批次
保守预留两种完整产量的空间，避免随机混合结果溢出丢失。堵塞时不消耗原料或流体。
JEI在同一输出槽轮播两个结果，注明各50%，不会显示为双产出。
