> 本文为2026-10-17机器快照，部分参数与配方覆盖已变化。当前科技线、默认能源参数和已接通的材料路线见[2026-10-20科技线总览](current-technology-tree.md)，逐条配方见[正式配方清单](technology-recipes.md)。

整理日期：2026-10-17。依据当前源码和正式配方资源；配置项按代码默认值列出，世界配置或数据包可以覆盖相应内容。本文区分机器已支持的功能和模组当前自带的配方。

## 加工机器

| 机器 | 核心与组件 | 工作内容 | 当前自带加工内容 |
| --- | --- | --- | --- |
| 粉碎机 | 工业核心＋正上方粉碎组件 | 物品粉碎，物品→物品 | 粗铁、粗铜、粗金各1份→对应粉末2份；煤或木炭1份→碳粉1份 |
| 锻压机 | 工业核心＋正上方锻压组件 | 独立锻压加工配方 | 暂无，需要数据包提供 |
| 塑形机 | 工业核心＋正上方塑形组件 | 物品→物品的塑形加工 | 暂无，需要数据包提供 |
| 灌注机 | 工业核心＋正上方灌注组件 | 物品＋流体/气体→物品 | 暂无，需要数据包提供 |
| 电弧炉 | 工业核心＋正上方煅烧组件 | 使用FE执行当前世界的熔炉熔炼配方 | 动态兼容原版及其他模组已加载的熔炼配方 |
| 合金冶炼机 | 工业核心＋正上方合金组件 | 物品＋物品/流体/气体→物品 | 炼钢；五级管道合金基体，随后接烧结、锻压或灌注 |
| 双相反应釜 | 工业核心＋正上方化合组件 | 两路输入、一路输出，按仓储介质识别9种模式 | 硫酸线：制硫、硫氧化、SO₂接触氧化、SO₃蒸汽水合 |
| 三相分离器 | 工业核心＋正上方分解组件 | 一路输入、两路输出，按仓储介质识别18种模式 | 水电解为氢气与氧气；使用独立分解配方 |
| 气液转化机 | 工业核心＋正上方气液转换组件 | 流体与气体转换，GUI切换气化/液化 | 硫酸气体1000 mB→液态硫酸1000 mB，100 tick、40 FE/t |
| 核反应堆 | 工业核心＋同高四周紧邻燃料棒 | 两路液体输入；输出核废料及热介质，不直接发电 | 浓缩铀/MOX/钍三种液体燃料各支持水冷、载热剂冷却；六条配方 |

选区内恰好一个工业核心，可放内部或外表面，无需居中。机型组件必须紧贴实际核心正上方，并包含在选区内；核反应堆通过同高四周燃料棒选型，不放上方组件。其他原机器核心保留注册ID，均已改为对应机型组件。

### 正式配方的基础参数

以下均为未升级、单份加工的数据，按20 tick/秒换算。

| 加工 | 输入→输出 | 时间 | 基础耗能 | 单份总耗能 |
| --- | --- | --- | --- | --- |
| 粗金属粉碎 | 1粗铁/粗铜/粗金→2对应粉末 | 100 tick，5秒 | 20 FE/t | 2000 FE |
| 制碳 | 1煤或木炭→1碳粉 | 100 tick，5秒 | 20 FE/t | 2000 FE |
| 炼钢 | 2铁粉＋1碳粉→2钢锭 | 200 tick，10秒 | 40 FE/t | 8000 FE |
| 水电解 | 1000 mB水→1000 mB氢气＋500 mB氧气 | 200 tick，10秒 | 60 FE/t | 12000 FE |
| 电弧炉熔炼 | 由已加载熔炼配方决定 | 沿用该熔炼配方时间 | 默认40 FE/t | 随配方时间变化 |
| 核反应堆水冷 | 1 mB燃料＋50 mB水→1 mB核废料＋50 mB蒸汽 | 1 tick，0.05秒 | 0 FE/t | 0 FE |
| 核反应堆载热剂冷却 | 1 mB燃料＋50 mB载热剂→1 mB核废料＋50 mB过热载热剂 | 1 tick，0.05秒 | 0 FE/t | 0 FE |

核反应堆需四列独立储罐；缺料、输出堵塞或结构损坏停止燃料加工，但余热仍需冷却；已加入分燃料等级的爆炸与辐射机制，见核安全文档。构建与流体ID见 [nuclear-reactor.md](nuclear-reactor.md)。

### 双相反应釜的9种模式

| 介质组合 | 模式 |
| --- | --- |
| 物品＋流体→流体 | 溶出制液 |
| 物品＋流体→物品 | 溶解析晶 |
| 流体＋气体→流体 | 液相捕收 |
| 流体＋气体→气体 | 液相生气 |
| 物品＋气体→物品 | 气固相炼 |
| 物品＋气体→气体 | 固转气化 |
| 流体＋流体→流体 | 液相合制 |
| 气体＋气体→气体 | 气相化合 |
| 物品＋物品→物品 | 固相熔合 |

异种输入介质可以交换输入通道；同种介质按配方指定通道放料。模式识别成功后仍需匹配具体配方。

### 分离器的18种模式

输入可以是物品、流体、气体，分别支持以下6种双输出组合，共18种模式：物品＋物品、物品＋流体、物品＋气体、流体＋流体、流体＋气体、气体＋气体。

同介质分解对应物品分解、流体分解和气体分解。两路输出必须同时有空间；分解使用独立配方，不自动反转反应釜配方。

## 范围作业机器

这4种机器均使用工业核心，在其正上方放对应组件。结构水平尺寸固定3×3，高度沿用多方块尺寸限制；均需要能量矩阵和至少27槽的输出仓。养殖塔另需至少27槽的食物输入仓，仓储只使用物品仓。

| 机器 | 组件 | 工作内容 |
| --- | --- | --- |
| 屠宰器 | 屠宰组件 | GUI选择目标生物类型；每轮按批量攻击目标，每次8点伤害，收集掉落物进入输出仓；未能装入的掉落物暂存 |
| 养殖塔 | 养殖组件 | 从输入仓取适配食物，为同种成年动物配对繁殖；一对消耗两份食物；默认范围动物数量上限64 |
| 收割塔 | 收割组件 | 收割成熟的常规作物、地狱疣、可可和甜浆果；保留种植需求并重置生长阶段，产物进入输出仓 |
| 驱逐塔 | 驱逐组件 | 通电期间抑制范围内敌对生物的新生成 |

默认以机器中心为基准，水平半径8格、上下各4格，即17×9×17范围。基础作业周期20 tick，基础20 FE/t；使用机器通用升级。范围机器在有电运行期间计费，即使当前没有可处理目标也会消耗电力。

## 抽液、发电与储能

| 设备 | 工作内容 | 当前默认参数或条件 |
| --- | --- | --- |
| 电动泵 | 单方块机器，抽取正下方紧贴的可汲取液体源；上方/侧面输出 | 基础20 tick、40 FE/t；16000 mB缓存；水/岩浆源通常一次1000 mB；GUI安装升级 |
| 太阳能发电机 | 见天空且处于白天时发电 | 80 FE/t |
| 月光发电机 | 当前实现为见天空即可发电，白天也工作 | 40 FE/t |
| 燃料发电机 | 消耗煤、木炭、煤块或模组电池发电 | 煤类默认40 FE/t；电池按各自功率和持续时间计算 |
| 储能矩阵 | 独立多方块电池；GUI切换仅充电、仅放电、动态平衡，并查看电网输入输出 | 每个能量矩阵100000 FE；整机充电、放电各共享10000 FE/t预算 |

储能矩阵不放加工核心或控制器，只接受能量矩阵、机器外壳、强化外壳和结构玻璃；边界完整，至少一个能量矩阵，内部可留空。供电桩覆盖其结构中心即可接入电网，也支持成员方块直接FE读写。

## 共用构建与运行规则

- 普通加工机器是完整长方体，默认各边3–16格；外表面恰好一个控制器，内部中心放核心，需要组件的机型在核心正上方放组件。
- 初次工程锤选择两个对角点；已有机器改装或修复后可右键原范围重检，无需重新框选。
- 普通机器至少一个能量矩阵。右键成型成员打开整机GUI，仓储本身作为实际加工缓存。
- 通用端口连接仓储列上端或下端，扳手切换输入1、输入2、输出1、输出2；同一列只能使用一个通道。
- 反应釜、灌注机、合金机使用输入1、输入2、输出1；分离器使用输入1、输出1、输出2；塑形机使用独立的物品输入1、输出1。
- 加工批次在一轮开始时锁定，受输入数量与输出空间限制。中途补料不扩大当前批次；输出堵塞、电量不足或结构损坏会暂停或停止相应操作。
- 机器从电网充入自身电池后加工；断网时可继续使用已存电量。普通机器默认电池容量为100000×（1＋能量矩阵数量）FE。

## 当前源码中的升级数值

| 部件 | 效果 |
| --- | --- |
| 能量线圈 | 每个加法减少20%基础耗能，单份最低1 FE/t |
| 效率线圈 | 每个速度＋15%，耗能倍率＋10% |
| 处理矩阵 | 每个并行上限＋1，耗能倍率＋15% |
| 能量矩阵 | 普通机器每个增加一份基础电池容量 |
| 强化外壳 | 为成型机器提供防爆保护 |

多方块升级无额外数量上限，受结构空间限制。电动泵升级槽遵循原版64堆叠。

当前单份每刻费用为：`max(1, ceil(基础耗能 × max(0,1−0.2×能量线圈＋0.1×效率线圈＋0.15×处理矩阵)))`，再乘实际加工份数。电动泵不使用处理矩阵。

## 仓储、管道与电网配套

- 每段物品仓27槽，竖向连接累加；GUI使用27/54槽分页，分页不改变实际容量。
- 每段储罐16000 mB，可存流体或气体；同列按实际介质连接，不能混装。
- 物品、流体、气体管道各5级。一级赤铜、二级殷钢、三级共振、四级超导、五级量子。物品速度为4/16/64/128/256个每秒；流体和气体为4000/16000/64000/128000/256000 mB每秒。
- 电网由一个核心和相连的信号杆、供电桩构成；GUI发起连线。信号杆最大80格，供电桩最大60格，线路取两端较小限制。
- 供电桩默认覆盖水平15×15、上下各5格，按实际工业核心判断供电。
- 教程书说明构建与操作；工程护目镜用于查看机器类型、运行状态、电量、耗能、速度和并行情况。

蒸馏塔、冷凝塔、交换塔：工业核心正上方搭配对应新组件，最小5×5×7，按塔内有效容积批处理。蒸馏/冷凝开顶且端口直连缓存，交换塔封顶并分隔上下空间；GUI调节每批容积百分比。默认配方及构建规则见 [处理塔](process-towers.md)。

硫酸线及空气分离塔：见 [硫酸产线](sulfuric-acid-line.md)。分离塔采用工业核心＋空气分离组件、5×5×7开口结构，GUI开启后耗电从空气产氮气/氧气，输出1/2独立缓存，无需输入或储罐。

矿物倍产：铁、铜、金支持直接粉碎2倍、氧气净化3倍、矿浆精炼5倍。高级线析晶后氢还原为矿团，共用中级粉碎尾段，并回收酸性母液，全部使用现有粉碎、灌注、反应釜、分离及熔炼机器。逐步配方、端口与净消耗见 [矿物倍产路线](ore-processing-design.md)，游戏内JEI和教程书提供相同说明。

非金属倍产：钻石、红石、青金石普通／深层矿石支持直接粉碎、氧气净化出矿团后粉碎、硫酸破晶后水洗为矿团再粉碎三档路线。中级两步、高级三步，共用粉碎尾段，不产生废液。固定产量与设备见 [非金属倍产](nonmetal-processing.md)。
