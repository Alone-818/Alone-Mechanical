# 右键交互修复

- 空储罐放置：恢复携带流体时，空值不会再调用 `FluidStack.EMPTY.setAmount(0)`。Forge 的空流体对象不可修改；原代码会在服务器放置阶段抛出异常，客户端却先显示放置预测。
- 管道：空手右键查看面的状态；持有管道或其他物品时让出操作，可连续放置。扳手右键查看状态、Shift＋右键切换面的模式，沿用现有规则。
- 发电机、电网节点和泵：持有方块时让出 GUI 交互，也支持主手为空、副手持方块。
- 储罐：Shift 切换模式、桶模式转移流体先于目标 GUI；普通放置仍走标准方块放置流程。
- 工程锤：优先处理方块点击，避免 GUI 抢占。普通点击仍可重检旧机器；Shift＋右键取消后，下一次点击强制选择新的第一角点，可位于旧范围内。完成第一点后恢复正常两点检测；取消标记存于物品 NBT。

回归入口：`tools/right-click-tests.gradle`；覆盖首次放空罐、管道连续放置、取消后在旧范围内重新框选，以及既有流体工具测试。无界面测试不能代替客户端画面验证。
