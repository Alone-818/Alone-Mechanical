# 储罐桶模式与取液枪

## 手持储罐

- 储罐物品不可堆叠，容量16000 mB；普通储罐与兼容旧存档的两种储罐均支持。
- 默认放置模式。手持时Shift右键方块或空气切换桶模式，再次切回放置模式。
- 桶模式右键世界液源，每次采集完整1000 mB；剩余容量不足1000 mB或液体不同则拒绝，液源不变。
- 桶模式右键储罐或兼容流体接口，优先装入手持罐；无法装入时尝试把手持罐内液体倒入目标。
- 切回放置模式即可放下带液储罐；拆除掉落保留本段液体，不复制整列液量。
- 展开Shift提示可查看模式、介质和液量。模式及液量都随物品NBT保存。

## 桶与已放置储罐

普通右键即可使用液体桶注液或空桶取液，操作优先于打开GUI，不再要求潜行。
竖向相连储罐按现有整体容量处理，不兼容介质或容量不足时拒绝，不把液体洒到世界。
成型机器内的储罐也允许这种手动交互；自动化仍遵循原有端口规则。

## 取液枪

杂项栏注册`alone_mechanical:fluid_sampling_gun`，不可堆叠，容量500 mB。
右键储罐或有可抽取流体接口的机器抽液，最多装500 mB，接口不足时装入实际余量。
已满或介质不同则停止，不消耗目标液体。满枪不会自动倒回目标。
按已确认规则，只从容器或机器抽取，不采集世界液源。Shift右键方块或空气均会清空，
该操作丢弃枪内液体，不向世界放液。液量随物品NBT保存，Shift提示显示介质和容量。

取液枪的生存合成配方尚未指定。
