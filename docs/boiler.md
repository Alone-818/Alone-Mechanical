# 锅炉

载热剂现具体为液态钠/高温液态钠，保留旧注册ID；已加入卤水与熔盐电解制备入口，见[钠载热剂](reactor-safety-and-void-ores.md)。

独立锅炉核心，最小3×3×3长方体。完整外壳、唯一表面控制器和至少一个能量矩阵；无机型组件。工程锤框选成型。

| 通道 | 介质 |
|---|---|
| 输入1 | 水，液体 |
| 输入2 | 过热载热剂，液体 |
| 输出1 | 蒸汽，气体 |
| 输出2 | 冷却后载热剂，液体 |

四列独立储罐，通过顶部或底部相邻的通用端口定义通道。竖向堆叠扩容。空输出1罐随配方准备为气体，已有不兼容介质不被清除。

默认50 mB水＋1 mB过热载热剂→50 mB蒸汽＋1 mB载热剂，1 tick（0.05秒），0 FE/t。过热载热剂与冷却载热剂是两个真实Forge流体，热状态由不同流体ID表示；不额外模拟连续温度。前者橙灰色 `#C5926F`，后者天蓝灰色 `#91B9C9`，都复用水的动态材质。仅加热流体转换成冷却流体才能提供蒸发所需热量。

默认配方ID为 `alone_mechanical:boiler_water_steam`，机器ID为 `alone_mechanical:boiler`，沿用 `alone_mechanical:machine` 配方类型。两个输入必须是液体，输出可分别使用流体/气体，一列仅一种介质；禁止物品输入输出。输入与两路输出按实际并行份数缩放，任一输出堵塞均暂停整轮；进度与批次支持存档。

载热剂通过流体管道传输，蒸汽通过气体管道传输，可供涡轮使用。载热剂现为液态钠，已加入卤水与熔盐电解制备，并由反应堆加热；载热剂没有专用桶，使用储罐与流体管道存储转运。本次不消耗岩浆。
