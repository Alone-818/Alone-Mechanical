# 核反应堆

2026-10-18新增钠载热剂制备、温度/余热、紧急停堆、燃料分级爆炸和辐射，详见[核安全与虚空矿石](reactor-safety-and-void-ores.md)。以下配方比例保留，冷却中断不再保证热堆安全。

工业核心作为中心，核心同高度、紧邻的东、西、南、北四格各放一个反应堆燃料棒方块。燃料棒是结构件，不消耗。上方不放机型组件。沿用最小 3×3×3 长方体、完整外壳、一个表面控制器、至少一个能量矩阵的规则，工程锤选择两角成型。

燃料棒方块暂不提供合成配方，继续作为核反应堆的结构件使用。

| 通道 | 介质 |
|---|---|
| 输入1 | 浓缩铀燃料、MOX燃料或钍燃料，液体 |
| 输入2 | 水或载热剂，液体 |
| 输出1 | 核废料，液体 |
| 输出2 | 水冷输出蒸汽（气体）；载热剂冷却输出过热载热剂（液体） |

四个通道各用一列独立储罐，通用端口紧贴仓列顶部或底部；竖向堆叠扩容。输入、废料列只能装液体，空的热介质输出列随配方准备为正确相态，已有不兼容介质不会被覆盖。任何一路缺料或输出堵塞时暂停整轮，不消耗输入、不单独生成另一产物。损坏结构停止加工，库存仍保留在实体储罐中。没有爆炸、熔毁、辐射机制。

三种燃料均有两条默认配方，每份 1 tick（0.05秒）、0 FE/t：

- 1 mB 燃料＋50 mB 水 → 1 mB 核废料＋50 mB 蒸汽。
- 1 mB 燃料＋50 mB 载热剂 → 1 mB 核废料＋50 mB 过热载热剂。

反应堆不直接产生FE。蒸汽接入涡轮，过热载热剂接入锅炉；处理矩阵的并行批次数会同比缩放两路输入与两路输出。默认配方已经是每刻完成，不会因为效率线圈突破每刻一次的处理下限。

| 流体ID（前缀 `alone_mechanical:`） | 色值 |
|---|---|
| `enriched_uranium_fuel` | 绿色 `#8AB94F` |
| `mox_fuel` | 橙色 `#CF8057` |
| `thorium_fuel` | 青色 `#7BBCC0` |
| `nuclear_waste` | 棕黄色 `#9A823E` |

均使用水的动态纹理，注册为真实Forge液体，使用流体管道与储罐转运，不注册专用桶。旧的空燃料棒、浓缩铀燃料棒、MOX燃料棒、钍燃料棒物品及其资源、物品标签已删除。保留铀矿、粗铀、铀粉和铀锭；燃料制备与废料再处理配方暂不提供。

机器ID为 `alone_mechanical:nuclear_reactor`，使用 `alone_mechanical:machine` 配方类型。六个 `nuclear_<燃料ID>_<water/heat_carrier>.json` 可由数据包覆盖。配方禁止物品通道，必须有两路液体输入、核废料液体输出及一路热介质输出，并保持零FE消耗。JEI列出六条配方，教程书含独立章节。

创造测试可使用 `/alonemechanical build nuclear_reactor` 生成空反应堆。需要测试燃料时，可通过带流体NBT的储罐物品提供，例如：

```mcfunction
/give @s alone_mechanical:storage_tank{BucketMode:1b,Fluid:{FluidName:"alone_mechanical:enriched_uranium_fuel",Amount:16000}}
```
