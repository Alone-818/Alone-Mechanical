# 电动泵

`alone_mechanical:electric_pump` 是单方块机器，放下即可工作。无需多方块外壳、核心或工程锤。

将泵放在液体源正上方。每轮只抽取紧贴底面的一个可汲取液体源，原版水和岩浆为1000 mB；普通流动液体不抽取。水浸方块通过桶取水规则排水，保留原方块。Forge `IFluidBlock` 液体通过其模拟/执行接口抽取。泵不搜索周围液池；水源是否自然再生遵循世界规则。

基础周期20 tick，40 FE/t，普通水/岩浆每轮耗800 FE。内部液体缓存16000 mB，电池基础容量读取机器电池配置（默认100000 FE）。由供电桩覆盖泵的位置，或从任意一面输入Forge Energy。没有液体源、缺电、缓存不足以装下整份源液体，或当前液体与缓存不兼容时停止抽取；空闲电池仍可由电网充电。

## GUI升级

右键泵打开GUI，下方是玩家库存，上方是液体、电池、状态和三个升级槽。直接放入对应的升级方块，也可Shift点击快速搬运。普通材料和其他方块不能放入升级槽。

| 槽位 | 升级方块 | 上限 | 效果 |
| --- | --- | --- | --- |
| 效 | 效率线圈 | 64 | 每个加15%速度、加10%耗能倍率，加法叠加 |
| 能 | 能量线圈 | 64 | 每个从基础耗能减20%，加法叠加，最终最低1 FE/t |
| 容 | 能量矩阵 | 64 | 每个增加一份基础电池容量，容量为基础×(1＋矩阵数量) |

升级不消耗方块，可从GUI取回。升级变化重置本轮进度，移除能量矩阵时按新容量裁剪剩余电量。处理矩阵用于多方块配方并行，泵不接受处理矩阵。

八个效率线圈的速度为220%，一次抽取需10个工作tick，耗能72 FE/t；再安装至少五个能量线圈后为1 FE/t。更换正下方液体种类也会重置抽取进度。液体、电量、升级、目标液体与当前进度保存在方块实体NBT中。

## 输出

顶部或侧面接流体管道，将管道靠近泵的端面设成“拉取”。底部为世界抽取口，不提供管道液体能力。外部液体接口只允许排出缓存，不允许向泵灌入液体。潜行持桶使用顶部/侧面可取出缓存液体。

拆除泵会掉落已安装的升级方块；泵本身按掉落表掉落。方块物品不携带液体缓存或电量。

## 开发检查

`ElectricPumpGameTests` 验证真实源块消耗、耗电、满罐与混液保护、流动液体跳过、水浸方块保留、升级限制、存档、电网断开、能力失效、GUI搬运、拆除掉落和现有流体管道拉取。

```powershell
./tools/verify_pump_resources.ps1
./gradlew.bat --offline runGameTestServer build
./tools/prepare_pump_test_world.ps1
./gradlew.bat --offline -I tools/pump-client-check.gradle runClient
```
