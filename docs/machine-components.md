# 工业核心与机型组件

所有加工、范围、锅炉、涡轮与核反应堆多方块共用一个工业核心。核心可位于选区内部或外表面，不要求几何居中；控制器仍须位于外表面。供电桩覆盖实际核心，范围机器也以实际核心定位。尺寸、完整外壳、能量矩阵及各机器仓储规则仍然适用。

除核反应堆外，在工业核心正上方紧贴一个机型组件，两者必须都在工程锤选区内：

| 组件 | 机型 |
| --- | --- |
| 粉碎组件（原粉碎核心） | 粉碎机 |
| 煅烧组件（原熔炼核心也改为此组件） | 电弧炉 |
| 锻压 / 塑形 / 灌注组件 | 锻压机 / 塑形机 / 灌注机 |
| 合金组件（原合金核心也改为此组件） | 合金冶炼机 |
| 化合组件（原反应核心也改为此组件） | 九种双相反应模式，由仓储介质决定 |
| 分解组件（原分离核心也改为此组件） | 十八种单入双出分离模式 |
| 气液转换组件（原转换核心） | 气液转换机，GUI选择方向 |
| 锅炉组件（原锅炉核心） | 锅炉 |
| 涡轮组件（原涡轮核心） | 涡轮发电机 |
| 屠杀 / 养殖 / 收割 / 驱逐组件 | 对应范围机器，平面3×3 |

核反应堆仍在工业核心同高的东、西、南、北紧邻位置各放一个燃料棒，不放上方机型组件，四根燃料棒都必须包含在选区内。

原方块注册 ID 保留，原其他核心现作为组件使用。旧结构需要改放工业核心与对应组件，再用工程锤选区或重新检测。快速建筑的所有模板已使用新规则，教程书“搭建演示”包含各机型布局。
