# 创造储罐

创造模式“孤独机械 · 杂项”中，每种已注册的源流体各有一个创造储罐，包含原版水/岩浆及本模组全部工艺液体。流动流体变体不重复列出。模组内置气体和当前加载机器配方中使用的气体也分别列出；同名液体/气体保持独立，例如液态硫酸与硫酸气体。

物品名标明固定供应的介质。放置后对应管道可从任意面抽取，无需电力或补充，不接受灌入。管道自身的速度等级仍生效。模拟抽取不会改变任何内容，多次实际抽取也不会耗尽。未配置的罐不会提供默认介质。

介质配置保存在方块和物品NBT中；存档恢复、创造中键复制和方块掉落均保留。紫色端盖区分普通罐，放置后显示对应液体或气体。此方块不是机器外壳或机器缓存，不会被普通多方块仓储汇总算法计入。

不提供生存合成配方。地狱/末地转换液专用桶物品及模型已移除；转换液本身和14个灌注配方保留，可用创造储罐、普通储罐与取液枪使用。

## JEI 与查看提示

JEI使用“介质相态＋介质ID”区分每个创造储罐，例如液态硫酸和硫酸气体分别为独立项目。子类型忽略改名等无关NBT，不会因同一个方块ID而合并所有介质。所有已注册的源流体、内置气体以及加载的机器配方涉及的气体都会明确补入JEI；流动流体不重复列出。

在JEI的创造储罐上按R查询生产该介质的机器配方，按U查询使用该介质的机器配方。机器配方中的关联是查询别名，真实消耗和产出仍为原有流体/气体，机器不消耗创造罐。无生产配方的介质仍可查看创造供应说明。配方更新后，目录补入新介质并移除已失效的配方专用气体。重复刷新不产生重复条目。JEI未安装时不会主动加载此集成的事件监听器。

Jade查看普通气体储罐时，容量数字改为独立文字行，进度条只画填充量，避免条内文字特殊描边导致的字形异常。查看创造储罐时显示固定介质和“无限供应”，不再以整数最大值表示有限容量。气体列的查看仍汇总整列，且不会抽取或改变实际存量。
