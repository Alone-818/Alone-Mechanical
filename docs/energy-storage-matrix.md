# 储能矩阵

用工程锤选择两个对角点，尺寸沿用 `maxMachineCubeSize`（默认每边 3–16）。边界必须完整，只允许机器外壳、强化外壳、结构玻璃、能量矩阵；内部可以留空，至少一个能量矩阵。不放核心、控制器、线圈、端口或仓储。

容量为能量矩阵数量 × `machineBatteryCapacityFE`，使用 long 持久化和同步。全结构共享每方向 `machineChargeRateFE` 预算（默认 10000 FE/t），不会因接入更多面而翻倍。

右键成员打开 GUI：仅充电拒绝所有输出；仅放电拒绝所有输入；动态平衡存入当刻发电余量，核心不足时按需放电。覆盖结构中心的供电桩负责关联电网，成员方块也支持直接 FE。

电网输入是外部输入与储能放电之和，输出是外部取电与储能充电之和，净流量为两者之差。悬停查看分项。所有数字仅计实际传输，显示上一游戏刻 FE/t；本矩阵统计也包含直接 FE 接口。

每维度 SavedData 只持有一份电量。结构损坏停用，原范围修复并重新锤定可恢复；拆光所有能量矩阵后删除记录。不强加载区块。完整扩建只转移一次电量，拒绝部分覆盖旧结构，容量不足时裁剪。
